% NOTE: the two corpora are NOT matched. apd is 53.8% PDF-derived chunks with the rest code and
%   markdown; passc is 98.2% PDF slide decks. This table exists so a reader can judge how far the
%   cross-subject comparison can be pushed, not to claim the two are equivalent.

    contamination easier to see. Neither corpus is a control for the other --- this table is the
    basis for judging how far Tables~\ref{tab:retrieval-quality-two-subjects}
