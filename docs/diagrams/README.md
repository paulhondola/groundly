# Diagrams

Thesis figures for the proposed use cases and interfaces ([design](../superpowers/specs/2026-11-09-use-cases-and-interfaces-design.md)).

| Diagram | Source | Rendered |
|---|---|---|
| Use cases | [groundly-usecases.json](groundly-usecases.json) | [groundly-usecases.html](groundly-usecases.html) |
| Architecture (proposed interfaces) | [groundly-architecture.json](groundly-architecture.json) | [groundly-architecture.html](groundly-architecture.html) |

The JSON is the source; the HTML is generated by [Archify](https://github.com/tt-a1i/archify) and opens offline in any browser. Its Export menu saves SVG or PNG for the thesis.

Each component cites the file and lines it is drawn from, at the commit pinned in `meta.repository`. After editing a source, rebuild its HTML from the repository root:

```bash
node <archify>/bin/archify.mjs finalize architecture docs/diagrams/groundly-usecases.json docs/diagrams/groundly-usecases.html --repo-root . --quality showcase --out-dir .archify/docs-build/usecases
```

`--out-dir` keeps the check receipts out of the repository. When the design changes through `/decision`, update both diagrams in the same change.
