# Groundly README refresh

The README should help a student get from course files to a cited answer and a browser quiz. Cover the capabilities in the published Groundly package and retain the thesis attribution.

## Approaches

- **Student-first walkthrough.** Use one subject for installation, a first cited answer, the topic map, and a test. Give mobile study and sharing dedicated examples. This is the selected approach.
- **Reference-first overview.** Give the CLI, MCP tools, and architecture equal weight. This works for readers comparing implementations and delays the first useful action for a student.
